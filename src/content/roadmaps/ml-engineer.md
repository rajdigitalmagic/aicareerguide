## 01 Programming
Python, Git, Linux, SQL, testing, APIs, and data handling.

## 02 Mathematics & Statistics
Probability, distributions, estimation, hypothesis testing, linear algebra, and optimization.

## 03 Machine Learning
Regression, classification, trees, ensembles, clustering, feature engineering, cross-validation, and evaluation.

## 04 Deep Learning
PyTorch, training loops, CNNs, transformers, regularization, and experiment tracking.

## 05 Production
FastAPI, Docker, CI/CD, monitoring, model versioning, and cloud fundamentals.

## 06 Projects
Build one classical ML system, one deep learning system, and one deployed production-style project.

## 07 Career
Prepare ML system design, software engineering fundamentals, DSA, project walkthroughs, and behavioral interviews.
